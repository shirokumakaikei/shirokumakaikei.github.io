ラズパイ(Raspberry Pi 4)に外付けHDD(4TB)をつないで、家の中のパソコンから共有フォルダとして使える NAS(ネットワークにつなぐ保存場所)を作りました。
機材費は合計26,478円です。電気代は計算式で見積もれます。
インターネットには公開せず、ルーターのポート開放もしない前提で使います。

## 手順

ここでは要点だけを書きます。細かいオプションや設定値は、[Raspberry Pi のドキュメント](https://www.raspberrypi.com/documentation/)と [Samba のドキュメント](https://www.samba.org/samba/docs/)にまかせます。

[[photo:p1]]

流れは5つです。

1. HDD を ext4 で初期化する
2. 起動時に自動でつなぐ設定を入れる
3. Samba を入れて共有フォルダを作る
4. 使っていないときの回転停止を設定する
5. バックアップを別に用意する

使ったのは Raspberry Pi 4(8GB)と、据え置き型の外付けHDD(4TB)です。据え置き型は電源をACアダプターから別に取るので、ラズパイ側の電源が足りなくなる心配が小さいのも利点です。

### HDD を NTFS から ext4 で初期化する

この HDD は元々 NTFS(Windows の形式)でした。NTFS のままでも読み書きはできますが、Linux で安定して動かしたかったので、ext4(Linux の標準的なファイルシステム)で初期化しました。

最初に、HDD がどのデバイス名で認識されているかを確認します。

```
lsblk
```

デバイス名は環境で変わるので、表示された容量などを手がかりに、HDD に当たるものを選びます。ここで間違えると別のディスクを消すので、必ず照らし合わせてください。以下は HDD が `sda` だった場合の例です。初期化すると中身は全部消えるので、残したいデータは先に退避します。

```
sudo parted /dev/sda mklabel gpt
sudo parted /dev/sda mkpart primary ext4 0% 100%
sudo mkfs.ext4 -L nas /dev/sda1
```

`-L nas` はラベル(名前)です。

### 外れていても起動が止まらない自動マウントにする

再起動しても HDD が自動でつながるように、`/etc/fstab` に書きます。ここがミソで、書き方を間違えると、HDD がつながっていないときにラズパイ自体が起動しなくなります。以前、つながっていないと起動が止まる設定の怖さを知ったことがあるので、今回は HDD が外れていても本体は起動するように `nofail` を付けました。

まずマウント先を作り、HDD の UUID(固有の識別子)を調べます。

```
sudo mkdir -p /mnt/nas
sudo blkid /dev/sda1
```

出てきた UUID を使って、`/etc/fstab` に次の1行を足します。

```
UUID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx /mnt/nas ext4 defaults,nofail,x-systemd.device-timeout=10 0 2
```

`nofail` が、HDD が無くても起動を続ける指定です。`x-systemd.device-timeout=10` は、デバイスを待つ時間を10秒に抑える指定です。デバイス名の `sda` は差し替えると変わることがあるので、UUID で書いています。

書いたら、再起動せずに確かめます。エラーが出なければ成功です。

```
sudo mount -a
df -h /mnt/nas
```

### Samba を入れて共有フォルダを作る

Windows から見えるようにするため、Samba(Windows と共有フォルダをやり取りするソフト)を入れます。

```
sudo apt update
sudo apt install samba
```

正直に言うと、ここで私は一度つまずきました。Samba はインストールしただけでは何も共有されません。共有したいフォルダの設定行を自分で書かないと、Windows 側で「アクセスできません」と出ます。

共有用のフォルダを作って所有者を自分のユーザーにし、`/etc/samba/smb.conf` の末尾に設定を足します。

```
sudo mkdir -p /mnt/nas/share
sudo chown user:user /mnt/nas/share
```

```
[nas]
   path = /mnt/nas/share
   read only = no
   valid users = user
```

Samba 用のパスワードは、OS のログインパスワードとは別に設定します。

```
sudo smbpasswd -a user
sudo systemctl restart smbd
```

設定ファイルの文法は `testparm` で確認できます。Windows のエクスプローラーのアドレス欄に `\\homeserver\nas` と入れると、共有フォルダが開きます。ホスト名は例です。名前で見つからないときは `\\192.168.x.x\nas` のように、ラズパイの家庭内アドレスで試してください。

### 使っていないときは HDD の回転を止める

HDD は、使っていなくても回り続けます。私は夏に機器をつけっぱなしにして暑い思いをしたので、常時動かす機器は少なく、静かにしたいと考えていました。そこで、一定時間アクセスが無ければ HDD の回転を止める設定を入れました。この記事の動作確認では、そのためのツールとして hd-idle を使っています。

```
sudo apt install hd-idle
```

設定ファイルの場所や書式、時間の指定のしかたはバージョンで変わります。インストールしたバージョンに付属する説明(README など)で、止めるまでの時間と対象のディスクを指定してください。回転を止めた HDD にアクセスすると、回転が戻るまで待たされます。待ち時間が気になる場合は、止めるまでの時間を長めにしてください。

## かかったお金

機材費は、購入当時の金額で次のとおりです。

- ラズパイ4セット(本体・電源・ケース・SD):15,800円(2021年7月購入)
- UPS拡張ボード V3(リチウム電池 4000mAh):2,698円(2021年8月購入)
- 外付けHDD Seagate Expansion 4TB(STEB4000304):7,980円(2021年8月購入)
- 合計:26,478円

いずれも購入当時の価格で、今の価格は販売ページで確かめてください。UPS拡張ボードは機材費の合計に含めていますが、この記事の手順では扱っていません。また、このラズパイは NAS のほかに、外出先からの接続(Tailscale)と写真の自動バックアップ(Immich)にも兼用しています。そのため、機材費と電気代は NAS だけの分ではありません。

電気代は、自宅で実測していません。そこで、次の計算式で見積もります。

消費電力(W)× 24時間 × 30日 ÷ 1000 × 単価(円/kWh)= 月の電気代

単価を31円/kWhとすると、常時1W の機器は 1 × 24 × 30 ÷ 1000 = 0.72kWh、0.72 × 31 ≒ 22円/月です。ラズパイと HDD の消費電力の合計(W)をこの22円に掛ければ、月の目安が出ます。消費電力は、各メーカーの仕様ページに載る公称値を当てはめるか、ワットチェッカーで実測してください。実際の消費電力は使い方で変わります。HDD の回転を止めている間は、さらに少なくなると考えられます。

単価の31円/kWh(税込)は、全国家庭電気製品公正取引協議会のよくある質問Q&Aに、令和4年7月22日に改定された目安単価として載っている数字です。目安単価は改定されることがあるので、最新の値は同協議会のQ&Aで確かめてください。実際の契約単価は電力会社やプランで変わります。

### クラウドと比べる

同じ容量をクラウドストレージで持つ場合は、容量ごとの月額を払い続けることになります。料金はサービスやプランで違い、改定もあるので、この記事には金額を書きません。比べるときは、使いたい容量(ここでは4TB以上)に当たるプランの月額を、各サービスの公式の料金ページで確かめてください。容量ちょうどのプランが無く、一つ上のプランになることもあります。

クラウドの月額が分かれば、次の式で機材費を回収できるまでの目安が出せます。NASの電気代の月額は、上の式で見積もった値を使います。

機材費26,478円 ÷(クラウドの月額 − NASの電気代の月額)= 回収までの月数

ただし、この数字は参考値にとどめてください。機材はすでに購入済みで、ラズパイは他の用途にも兼用しているので、新しく買う人の損益分岐とは別物です。NAS は自分でバックアップを用意しないと、機器の故障で中身を失います。クラウドは保管の仕組みをサービス側が運用しますが、データの複製のしかたや保証内容はサービスごとに違うので、同じ土俵の比較ではありません。金額だけ見たときの目安として読んでください。

## 経理の目線で見ると

経費にできるかどうかは、立場で変わります。ここでは個人事業主が事業で使う場合の原則を、国税庁の説明から整理します。

### 事業と私用の按分

国税庁のタックスアンサー「No.2210 必要経費の知識」では、家事上の費用は必要経費にならないが、一つの支出が家事上と業務上の両方にかかわる費用(家事関連費)がある、と説明されています。そして、この家事関連費のうち必要経費になるのは、「取引の記録などに基づいて、業務遂行上直接必要であったことが明らかに区分できる場合のその区分できる金額に限られます」とされています。

この NAS は、写真のバックアップなど私用にも使っています。仕事用と私用をどう分けるか、電気代をどう按分するかは、使い方の記録を残したうえで、区分できる根拠をもって決める必要があります。

### 10万円未満の機材の扱い

「No.2100 減価償却のあらまし」では、使用可能期間が1年未満のものまたは取得価額が10万円未満のものは、その取得に要した金額の全額を業務の用に供した年分の必要経費とするとされています。取得価額が10万円以上20万円未満の減価償却資産には、一括償却の取り扱いがあります。

このほか、青色申告者には少額減価償却資産の特例があります。同ページでは、令和8年3月31日までに取得した場合は取得価額10万円以上30万円未満、それ以降の取得は40万円未満(取得の期限は令和11年3月31日まで)が対象で、合計300万円までという上限が示されています。要件や期限は改正で変わることがあるので、最新の内容は国税庁の案内で確かめてください。ただし、これらは業務の用に供した資産についての説明です。私用にも使う機材は、上の按分の考え方も関わります。

ラズパイのセットのように複数の物をまとめて買った場合に、どの単位で判定するかなどは、国税庁の記述を超えて当てはめないでください。

会社員の副業なのか、個人事業主なのか、法人なのかでも扱いは変わります。実際に経費として処理するかどうかは、領収書や購入履歴などの資料を原則どおり保存したうえで、税務署や税理士に確かめてください。この記事は個別の税務助言ではありません。

## 仕事でどう使えるか

個人事業主・士業・小規模事務所の仕事では、次のような使い方が考えられます。

- 事務所内のパソコンから使える共有フォルダとして、書類や資料を置く
- パソコンのバックアップ先にする
- スキャンした書類の保管場所にする

月額で課金されるクラウドと違い、容量を増やすときは HDD を足せばよいので、保管量が増えても月額が膨らみません。一方で、保守は自分で行う必要があります。故障したときの復旧、更新、バックアップの管理を担える人がいない事務所は、クラウドのほうが向いています。

## 注意点

### バックアップは別に用意する

HDD が1台だけの NAS は、その1台が壊れたら中身も一緒に失われます。NAS は便利な保存場所であって、バックアップではありません。

大事なデータは、別の HDD にコピーを取るか、別の場所にも置いてください。失くすと困るフォルダを決めて、定期的に別のディスクへコピーする仕組みを作るところからで十分です。

### 顧客のデータを置く場合

仕事で顧客のデータを置くなら、守秘義務や個人情報の安全管理を意識する必要があります。具体的にどの法令のどの義務が自分に当たるかは、業種や立場で変わるので、所属団体や専門家に確かめてください。置くなら次の3つは最低限そろえてください。

- バックアップ(別の場所にもコピーを持つ)
- 暗号化(盗難や紛失に備える)
- アクセスできる人の管理(`valid users` で絞る)

家庭用の機材と同じ感覚で顧客データを置くのは避けてください。

## セキュリティ(外部に公開しない設定)

この NAS は、ルーターのポート開放をしません。Samba をインターネット側に出す使い方は、この記事の範囲に入れていません。家の中のネットワークだけで使います。

設定面で気をつけたのは、次の点です。

- 共有に `valid users` を付け、誰でも入れる設定にしない
- Samba のパスワードは、OS のログインパスワードとは別にする
- OS とパッケージの更新を止めない(`sudo apt update` と `sudo apt upgrade` を定期的に行う)
- 使わない機能(今回なら Samba の共有以外)は動かさない

外から使いたくなったときも、ポート開放ではなく、VPN などの別の方法を検討してください。
